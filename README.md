# ☕ Cafe Coffee Day Sales Dashboard

## 📌 Project Overview

An **Excel Sales Dashboard** built to analyze Cafe Coffee Day sales data and identify key business trends and performance insights.

## 🎯 Objective

* Analyze overall sales performance
* Identify top-selling products
* Compare sales by city, store, and category
* Analyze monthly sales trends
* Understand customer payment preferences

## 🛠️ Tool Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Excel Formulas
* Data Visualization
